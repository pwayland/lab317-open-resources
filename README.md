# Lab 317 Open Resources

Public guides, templates, examples, and other reusable materials from Lab 317 at Inter American University of Puerto Rico, Metropolitan Campus.

## Status

This repository is being prepared for its first public release. No internal project files are published automatically.

## Resources

Published materials will be organized in [`resources/`](resources/README.md). Each resource should include enough context to understand, adapt, and cite it.

## Publishing standard

Before adding a resource, confirm that it:

- contains no personal, student, personnel, financial, contractual, credential, or other restricted information;
- can legally be shared, including embedded images, data, quotations, and third-party materials;
- identifies its author, source, date, and version where relevant;
- is understandable without access to Lab 317's internal workspace; and
- has an explicit license or reuse statement appropriate to that resource.

Internal working material remains in the private Lab 317 workspace. This repository is the canonical home only for material deliberately approved for public release.

## License

No repository-wide license has been selected yet. Individual resources must not be treated as licensed for reuse unless their own folder or file explicitly says so.
