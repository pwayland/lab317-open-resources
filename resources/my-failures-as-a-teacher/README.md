# My Failures as a Teacher

[Download the presentation](my-failures-as-a-teacher.pdf)

## Purpose

This reflective presentation uses examples from Paul Wayland's teaching practice to examine how assessment choices shape course design and student learning. It traces a move from test-centered instruction toward competencies, concepts, and project-based learning.

## Intended audience

University faculty, academic leaders, assessment professionals, and others working on teaching quality and student retention.
