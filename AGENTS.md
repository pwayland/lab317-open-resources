# AGENTS.md — Lab 317 Open Resources

This is a public repository. Treat every committed file and its history as publicly visible.

## Scope

- Maintain public-ready Lab 317 guides, templates, examples, and reusable materials.
- Keep internal planning, drafts, operational records, and private source collections outside this repository.
- Do not copy whole directories from the internal `317 - General` workspace.

## Required checks before publication

- Remove personal data, student records, personnel files, financial details, credentials, private correspondence, and restricted institutional information.
- Confirm copyright and permission for text, images, datasets, software, and third-party material.
- Preserve useful attribution, source dates, version information, and accessibility.
- Give each resource an explicit license or reuse statement. Do not infer a repository-wide license.
- Inspect staged changes and repository history before pushing.

## Working style

- Prefer small, self-contained resource folders with their own README.
- Use plain, audience-facing language; do not assume access to internal Lab 317 context.
- Keep generated files only when they are the intended public deliverable and retain an editable source when practical.
- Verify links and render documents before release.
